Tiled Models

Patrick Morrison, 8 February 2026

This is the short, practical guide for using 3D Tiles in BelowJS. If you only read one page, use this one.

What BelowJS Expects

  • Load from the root tileset.json URL.
  • Do not point BelowJS at a raw .3tz file.
  • Tile content can be .glb or .b3dm; .glb tile content works well.

Fast Path (Metashape .3tz)

Metashape often exports .3tz. Convert it once, then load the resulting folder.

# From repository root
examples/tileset/convert-3tz.sh

# Output:
# examples/tileset/AwhinaTiled_tiles/tileset.json

The script does two steps:

  1. Convert .3tz to an unpacked tileset folder.
  2. Upgrade to 3D Tiles 1.1 with .glb tile payloads.

Load It in the Example

http://localhost:5173/examples/tileset/index.html?url=http://localhost:5173/examples/tileset/AwhinaTiled_tiles/tileset.json&up=+Z

For Metashape data, up=+Z is usually correct. For NASA-AMMOS sample data, use up=-Z.

Minimum Viewer Settings That Matter

{
  type: 'tileset',
  url: '.../tileset.json',
  up: '+Z',
  autoCenter: true,
  maxTriangles: 1000000
}
  • up: fixes orientation.
  • autoCenter: keeps positioning sane for navigation and framing.
  • maxTriangles: useful for keeping VR smooth.

Textures and Material Notes

  • Metashape tiles can use KTX2/BasisU (KHR_texture_basisu).
  • 3D Tiles can be authored as unlit. BelowJS handles conversion for interactive lighting use cases.
  • If a dataset still looks flat, check that you are loading the converted tileset and not stale output.

Single File vs Streaming

  • If you want true single file delivery: use one .glb model (no tile streaming).
  • If you want large-scene streaming: use 3D Tiles (tileset.json + many tile files).

Troubleshooting

  • Wrong orientation: set up=+Z (Metashape) or test -Z/+Y quickly via URL params.
  • Won't load: serve via HTTP(S), not file://.
  • 3D Tiles 1.1 warning: some newer features/extensions may still have partial support depending on dataset.
  • Performance drops in VR: lower maxTriangles, increase error target, or simplify source data.
