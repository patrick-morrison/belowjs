Tiled Models

Patrick Morrison, 8 February 2026

This is a practical guide for using 3D Tiles in BelowJS.

⚠️ Experimental: 3D Tiles support is under active development. It works well for most datasets, but test your specific tileset early to catch edge cases.

Do You Need Tilesets?

Most projects should stay with a single .glb file. It is easier to host, easier to debug, and usually performs well after optimisation. As a rule of thumb, keep single-file delivery when you can stay at or below ~1.2 million polygons and ~100 MB. Move to 3D Tiles when the optimised model still exceeds those limits, or when the site is large enough that level-of-detail streaming is needed.

Metashape to BelowJS

Metashape exports tiled datasets as .3tz, which is an archive. BelowJS does not load the archive directly; it loads the root tileset.json inside the converted folder. The workflow is: export 3D Tiles (*.3tz) in Metashape, run the conversion script in this repo, then load the resulting tileset.json URL in the tileset example.

examples/tileset/convert-3tz.sh
http://localhost:5173/examples/tileset/index.html?url=http://localhost:5173/examples/tileset/wreck-tiles/tileset.json&up=+Z

Live example: BelowJS 3D Tiles streaming demo.

For orientation, start with up=+Z for Metashape exports. If the model is rotated incorrectly, test +Y, -Y, or -Z.

Viewer Config and VR

{
  type: 'tileset',
  url: '.../tileset.json',
  up: '+Z',
  autoCenter: true,
  maxTriangles: 1000000
}

In this config, url must point to the root tileset.json, up sets axis orientation, and autoCenter keeps navigation stable. The key performance control is maxTriangles. For Quest 3, start around 750000 to 1000000. For Quest 2, start lower.

The loader streams tiles by camera view, showing coarse tiles in the distance and refining detail where you are looking. In VR it adapts detail in real time against the maxTriangles budget by adjusting errorTarget, which helps keep frame rate stable while moving. If performance drops, lower maxTriangles first, then increase errorTarget (for example 16-20).

Troubleshooting

Tileset does not load

Serve over HTTP(S), not file://. Confirm the URL points to tileset.json.

Model is sideways or upside-down

Set the correct up axis. Try +Z, -Z, +Y, -Y.

VR performance is poor

Reduce maxTriangles (for example 500000 on Quest 2, 750000 on Quest 3), then increase errorTarget.

Textures look wrong

Re-run convert-3tz.sh and check terminal errors. Bad source tiles can also cause this.
