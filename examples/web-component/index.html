<below> Web Component

Embed 3D models easily with a simple HTML element, similar to <model-viewer>

Basic Usage

Just add a src attribute to load a model. That's it!

<below src="model.glb" name="My Model" ></below>

With Measurement Tools

Add the measurement attribute to enable precise measurement capabilities.

<below src="model.glb" measurement theme="light" background="#f8f9fa" ></below>

Full Featured

Enable all features: VR, measurement, dive mode, fullscreen, and screenshot.

<below src="shipwreck.glb" name="Historic Shipwreck" vr measurement dive fullscreen screenshot ></below>

Custom Camera Position

Set initial camera position and target using attributes.

<below src="model.glb" camera-x="20" camera-y="15" camera-z="25" target-x="5" target-y="0" target-z="0" ></below>

JavaScript API

Access the underlying viewer and Three.js objects programmatically.

// Get the element const viewer = document.querySelector('below'); // Listen for events viewer.addEventListener('load', (e) => { console.log('Model loaded!', e.detail); }); // Access methods viewer.resetCamera(); viewer.takeScreenshot(); viewer.focusOn({ x: 0, y: 0, z: 0 }, 10); // Access Three.js objects const camera = viewer.getCamera(); const scene = viewer.getScene(); const model = viewer.getModel();

Attributes Reference

Attribute Type Description
src string URL to GLB/GLTF model file
name string Display name for the model
credit string Attribution/credit text
background color Background color (default: #041729)
theme "dark" | "light" UI theme for measurement panel
vr boolean Enable VR support
ar boolean Enable AR support
measurement boolean Enable measurement tools
dive boolean Enable dive mode effects
fullscreen boolean Show fullscreen button
screenshot boolean Show screenshot button
camera-x/y/z number Initial camera position
target-x/y/z number Initial camera target
poster string Poster image shown while loading
